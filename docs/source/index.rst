DENVtoFHIR
==========

DENVtoFHIR is a Nextflow pipeline that turns Dengue virus (DENV-1 to DENV-4) amplicon or
whole-genome sequencing data into serotype calls, depth-masked haploid consensus genomes,
Nextclade genotype and lineage classifications, and HL7 FHIR R4 resources conforming to the
Genomics Reporting IG 3.0.0.
